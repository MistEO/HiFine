## 挑片与整理

- 左侧缩略图支持多选。按住 Ctrl（Mac 上用 ⌘）逐张挑，按住 Shift 连选一段。选好后可以一起复制、剪切或移到回收站，点缩略图底部的多选按钮就能查快捷键。
- 可以把复制或剪切的照片粘贴到当前打开的照片文件夹。遇到重名会自动加序号。右键选中的缩略图可以操作整组，右键旁边的一张则能单独处理它，大图仍留在眼前。
- 看中一张照片时，按回车或点右上角的“打开文件位置”就能在系统文件管理器中找到它。上下方向键也能翻照片，直接启动 HiFine 时有三张示例可以试。
- Windows 上，图片解码和 GIF、WebP 动图播放期间也可以移动或重命名原文件。
