## 软件更新

- 从本版起，HiFine 每次启动都会在后台通过 Mirror 酱检查更新。CDK 留空时，发现新版会在窗口底部提示。
- 在“设置 → 软件更新”中保存 Mirror 酱 CDK 后，下次启动会随版本查询一并发送。发现新版时，HiFine 会直接使用同一次响应中的链接下载对应平台的安装包，校验 SHA-256 后打开。安装由你确认。[Mirror 酱项目页](https://mirrorchyan.com/zh/projects?rid=HiFine&source=hifine_release)
- Windows 安装程序新增欢迎页。可以先关闭正在运行的 HiFine，再点“安装”。

## 图片缓存

点击右上角的“设置”，可调整缓存的图片张数和像素内存上限，默认是 8 张、256 MiB。保存后立即生效，下次启动也会沿用。单张图片超过上限仍可正常查看。
