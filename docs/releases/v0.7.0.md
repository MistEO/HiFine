## 看图与更新

- 左侧缩略图可以从顶栏一直排到底栏。「只看星标」移到左下角的翻页按钮旁，快捷键列表可以点右上角的键盘图标打开。也可以按 **Shift+F** 筛选星标，按 **F1** 查看快捷键。
- 在「设置 → 软件更新」里填入或更换 Mirror 酱 CDK 后，点保存就会立即验证。窗口底部会显示检查结果，CDK 无效、过期或当天下载次数用完时会弹窗说明。验证通过且有新版时，HiFine 会下载并打开安装包。
- 修复了小窗口里设置说明和照片信息被裁切的问题。照片信息里的长文件名现在会自动换行，也可以选中复制。
