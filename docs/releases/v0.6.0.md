## 看图操作

- 星标移到了顶栏的「文件位置」旁，右上角可以切换照片信息、全屏或进入设置。底栏左侧翻图和控制动图播放，右侧调节缩放。浏览缩略图或大图时，回车依然能定位原文件，Tab 依然能切换照片信息。
- 按 **F** 给当前照片加星，再按 **Shift+F** 就能只看这个文件夹里的星标照片。
- 按 **F1** 或点缩略图下方的「快捷键」可以查看完整按键表。用 **F6 / Shift+F6** 在主窗口前后移动焦点，按空格或回车操作选中的按钮。
